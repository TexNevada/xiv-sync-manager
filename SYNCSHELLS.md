# Native syncshell contracts

Source inspection, not an in-game compatibility claim. The manager uses the loaded plugin's own membership and permission state. It never contacts a sync server directly, creates a membership cache, or substitutes per-player actions.

All permissions shown are the current user's native shell settings, not admin defaults or a prediction of effective per-member behavior. Every write preserves all other bits from the latest native shell state. Lightless uses its ready connection session; Snowcloak waits for native reconciliation when the client exposes that signal. PlayerSync and older Snowcloak versions read the current mask through their native `GroupsGetAll` endpoint on click rather than writing from a registry that may be stale after reconnect. That read is not cached and a changed connection aborts the action. A successful transport task alone is not confirmation: the manager waits for provider readback. The native profile viewer remains responsible for fetching and reporting inaccessible content.

## In-game acceptance checklist

- Check compact rows at the default window size and with a long shell name. Service shows Lightless, Snowcloak, or PlayerSync; Syncshells shows the shell name. The left arrow expands the provider's native `GroupPairs` roster by GID beneath the shell name (Lightless exposes it on its collection view). Compare against the native list with all members offline. Check empty and unavailable rosters, including shells with the same display name. Member lists are read only for expanded, visible shells; aliases fall back to native UIDs.
- Check that Pause and Resume use the native-style pause and play icons, unsupported pause shows `N/A`, and each media control stays on the same line while pending. Confirm the app's amber/yellow treatment for Off and green for On, including in the PaperAndInk theme.
- With all three loaded, compare joined shells against the native menus, including an empty shell and same-named shells. Toggle each provider and confirm only its rows hide. Turn off automatic duplicate management and repeat.
- In Lightless and Snowcloak, pause and resume with zero nearby members, then with all members offline if possible. Confirm both directions in the native menus without waiting for a member to appear. Confirm that an existing manager-owned pair pause remains set.
- For each provider, change one media setting at a time. Check the corresponding native setting, the other two flags, and any unrelated individual pair permissions. Change it back in the native menu and verify the manager refreshes.
- Open each supported native profile, including two same-named shells in succession. Test a hidden/unavailable profile in the native viewer. Check that Snowcloak's disabled `N/A` profile button matches the size of `Open` and explains why on hover.
- Disconnect or unload one provider while keeping the other two loaded. Check list and action status before and after reconnect; no request should replay. Reload the manager and verify it reads shell settings from the plugins again.
