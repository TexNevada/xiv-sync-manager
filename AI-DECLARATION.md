# AI Declaration

## Use of AI in this project

This project is developed and maintained with assistance from AI tools.
Different models and providers may be used over time.

AI assistance may include planning, implementing and editing code,
troubleshooting, writing documentation, and suggesting improvements. AI
contributions can be substantial, and their extent varies by task.

## Human oversight

The maintainer sets the project's direction and decides which changes to
accept and release. Responsibility for understanding, reviewing, and
validating the work remains with the maintainer.

AI-assisted output requires human review and appropriate verification before
release. Verification may include code review, builds, automated checks, and
manual testing. Remaining verification needs should be documented in the
project's README or release notes.

## Tool and command access

Depending on the permissions granted, AI tools may read and edit repository
files and run development commands, including build tools and Git commands.

The maintainer controls the permissions granted to those tools and remains
responsible for the resulting changes and release decisions.

## What this means for you

- **AI involvement is disclosed.** AI may contribute to both the code and
  documentation.
- **Verification matters.** AI output can contain mistakes. A successful build
  does not establish that every feature works correctly in its intended
  environment.
- **Provided as-is.** The software is provided under the terms of the
  repository's [LICENSE.md](LICENSE.md), including its warranty limitations.

## Questions

If you have questions about AI use or the project, feel free to open an issue
on the repository.
